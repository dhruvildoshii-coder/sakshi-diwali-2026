# Sakshi’s Diwali ✨

A personalised, mobile-first Diwali surprise website.

## Files
- `index.html` — website structure and personal letter
- `style.css` — visual design and animations
- `script.js` — interactive activities
- `assets/` — your 10 photos and the Soniyo audio track

## Preview locally
Open `index.html` in a browser. For best results, use a local web server (for example VS Code Live Server).

## Publish with GitHub Pages
1. Create or open a GitHub repository.
2. Upload **all contents** of this folder (not just the ZIP).
3. Go to **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. Wait for GitHub Pages to publish and open the provided URL.

Keep the `assets` folder beside `index.html`; the website uses relative paths.

## Music
The supplied `Soniyo` MP3 is included in `assets/soniyo.mp3`. iPhone browsers require a user tap before audio can play, so the song starts from the Play button in the final letter.
